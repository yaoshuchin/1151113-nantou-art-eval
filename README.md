# 115南投國中美術班評鑑 — 孕育一棵藝術大樹

南投縣立南投國民中學 115 學年度藝術才能美術班訪視評鑑專屬互動系統。

## 系統特色
- **📊 簡報展示模式**：完整網頁化 16 頁簡報，內建校長講稿與重點指引、單頁/全頁流暢瀏覽切換。
- **💡 B 模式（問答教戰）**：評鑑委員 8 大高頻提問模擬、應答主軸與數據佐證。
- **🗺️ C 模式（流程動線）**：訪視當日時程表、8大創作工坊走訪動線、司儀引導講稿與接待檢核表。
- **📝 D 模式（現場紀錄）**：委員提問即時記錄表、一鍵複製 Markdown 與一鍵列印支援。
- **🎨 客製化設定**：最上方提供「字體大小（大/中/小）」與「布景主題（淺/深/藍/綠）」即時切換。
